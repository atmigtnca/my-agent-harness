# 세션 마무리 위키 기록

> **발동 선언**: 이 스킬을 실행할 때 "wiki-record 프로토콜 발동합니다"라고 선언하고, 실행 중·보고에서도 같은 명칭을 쓴다.

규칙의 원본은 `wiki/SCHEMA.md`다 — 먼저 읽고, 이 스킬과 충돌하면 SCHEMA가 이긴다.

이 스킬이 세션 지식을 위키에 남기는 마지막 기회다: 세션 종료 후 자동 수거는 없으므로,
여기서 기록하지 않은 지식은 세션과 함께 사라진다. 사용자가 자리에 있으므로 승인을 받아
곧장 `verified`로 남긴다.

## 절차

### 1. 회고 — 후보 추출

현재 세션 대화 전체를 훑어 기록 트리거(SCHEMA "기록 트리거" 절)에 해당하는 지식을 추출한다:
① 30분+ 삽질의 해결책 ② 반복 질문의 답 ③ 운영 사고의 원인·해결 ④ 프로젝트 구조·인프라 결정 ⑤ AGENTS.md 심화

- 확신 없으면 버려라 — 누락이 노이즈보다 낫다. 트리거에 안 걸리는 "그래도 유용할 듯"은 기록하지 않는다.
- 후보를 표로 제시한다: 제목 / 트리거 번호 / 유형·위치 / 한 줄 요지. 사용자가 기록할 것을 고른다.
  이 선택은 **작성 범위의 합의일 뿐 승인이 아니다** — 본문 승인은 4단계에서 문서 단위로 따로 받는다.
- 후보가 없으면 없다고 말하고 끝낸다. 빈 세션에서 억지로 만들지 마라.

### 2. 중복·삭제 기록 확인 — 선택된 각 후보마다

- `grep -ri "<키워드>" wiki/` — 기존 문서가 있으면 새 문서 대신 그 문서를 고친다
  (verified였다면 수정 시 draft 강등 — 4단계 승인을 받으면 그 자리에서 재승격).
- `git log --diff-filter=D --oneline -- wiki/` — 같은 주제의 삭제 기록(커밋의 삭제 사유)이 여전히 유효하면
  쓰지 않는다. 사유가 해소됐을 때만 예외 — 본문에 해소 근거를 명시한다.

### 3. 작성 — SCHEMA 스펙 그대로

- **기록 위치**: 위키는 하나다 — 모든 문서는 `wiki/<섹션>/`에 쓴다. 판정할 것은 어느
  섹션이냐뿐이고, 기준은 SCHEMA frontmatter `config.sections`와 "프로젝트 규약" 절이다.
- 유형·위치: 사고 → troubleshooting(증상·원인·해결·재발 방지 4섹션 + frontmatter `symptoms:`),
  결정 → decision(`adr-NNN-*`), 그 밖의 지식 → knowledge. **섹션 배치는 SCHEMA의
  frontmatter `config`와 "프로젝트 규약" 절이 정한다** — 시공 전이면 기록할 수 없으니
  `/wiki-start`를 먼저 안내하라.
- frontmatter 필수 항목(`summary`, `sources`, `review_by`, 그리고 config에 태그가 정의됐으면 `tags`)과
  300줄 상한은 SCHEMA 표를 따른다.
- 세션 서사를 옮기지 말고 지식만 증류하라 — "우리가 X를 했다"가 아니라 "X는 이렇게 동작한다".
- 에러 메시지·명령어·로그 발췌는 표현을 다듬지 말고 **세션 원문 그대로** 옮긴다 —
  미래 세션의 grep이 적중하는 지점이다.

### 4. 승인 — 문서 단위

- 문서 단위로 SCHEMA "기록 경로"의 승인 절차를 그대로 따른다 — 본문 제시·이름 명시·
  승인 후 `verified`(decision은 `accepted`) 처리·거절과 수정 요구의 처리 전부 그 절이 원본이다.

### 5. 커밋

- 승인 단위마다 SCHEMA 장부 형식으로 커밋한다:
  `wiki: 기록 — <파일명>: <요지> (승인: <이름>)` (기존 문서 승격이면 동작을 `승격`으로).
- `wiki/index.md`는 직접 편집하지 않는다 — wiki-lint(pre-commit)가 재생성한다.
- wiki/ 밖의 파일을 이 커밋에 섞지 않는다.

## 자율 세션이면

자율 세션(정의와 처리는 SCHEMA "자율 세션 예외")에서 이 스킬이 호출됐다면 1단계 후보 선택도
4단계 승인도 묻지 않는다. 이 스킬 고유 차분: 5단계 커밋의 동작은 그대로 `기록`이고,
제목 끝의 승인 표기 `(승인: <이름>)`는 붙이지 않는다.
